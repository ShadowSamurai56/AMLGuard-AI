# Data Directory (`data/`)

This directory houses the synthetic banking transaction records generated by IBM's **AMLSim** (Agent-Based Multi-Agent Simulation Engine) alongside serialized offline parquet caches utilized by the Streamlit workbench.

---

## 1. AMLSim Simulation Records

The raw CSV files represent an agent-based simulation of a synthetic banking network designed to capture realistic financial behavior and money-laundering typologies without privacy risks.

| File | Rows | Size | Description |
|---|---|---|---|
| `accounts.csv` | 1,446 | ~240 KB | Bank account master entities, including synthetic attributes (account type, model parameters, bank ID). |
| `transactions.csv` | 41,657 | ~2.5 MB | Directed transaction ledger capturing source/target accounts, step timestamps, amounts, and currency types. |
| `alert_accounts.csv` | 80 | ~3.5 KB | Ground-truth malicious entities tagged with model simulation alert IDs and specific laundering typologies. |
| `alert_transactions.csv` | 192 | ~4.9 KB | Individual illicit transactions tagged as participating in simulated money laundering schemes. |

### Laundering Typologies Simulated:
- **Cycle ($n=4$ test rings):** Circular wash-trading chains where funds rotate through intermediate shell accounts ($A \rightarrow B \rightarrow C \rightarrow A$) to obscure origin while netting close to zero net volume.
- **Fan-In / Gathering ($n=6$ test patterns):** Smurfing / structuring schemes where multiple small-value sources funnel capital into a centralized consolidation node.
- **Fan-Out / Scattering ($n=6$ test patterns):** Layering schemes where consolidated illicit capital is rapidly dispersed across numerous recipient nodes to evade threshold reporting.

## 2. Streamlit Parquet Cache (`data/cache/`)

To support instantaneous cold-starts and low-latency interactive investigation on **Streamlit Community Cloud** (where an active MySQL instance is unavailable), raw tables and features are compiled into columnar Apache Parquet files.

| File | Size | Description |
|---|---|---|
| `amlsim_features.parquet` | ~96 KB | 17 engineered behavioral features across all 1,446 accounts (turnover velocity, in/out ratio, counterparty diversity, flow volatility). |
| `amlsim_transactions.parquet` | ~606 KB | Indexed transaction ledger for rapid 1-hop ego-network retrieval and audit trail rendering. |
| `amlsim_alerts.parquet` | ~7 KB | Ground-truth SAR tags and typology categorizations. |
| `elliptic_sample_features.parquet` | ~127 KB | Subset of 166-dimensional Bitcoin node features for UI demonstration. |
| `elliptic_sample_edges.parquet` | ~4 KB | Directed payment edges connecting sample cryptocurrency transactions. |

The caching layer is managed automatically by `src/app/data_manager.py` via `@st.cache_data`.
